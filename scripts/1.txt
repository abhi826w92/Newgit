**Kya hai:** Video chalte waqt user home button dabaye → video chhota floating window me chalta rahe, app minimize hone ke bawajood.

**UI/UX:**
```
┌──────────────────────┐      ┌──────────────────────┐
│  ← WatchHub    [PiP] │      │                      │
│ ┌──────────────────┐ │      │   (baki screen        │

**Code:**

- `WebActivity.kt` → button pe `enterPictureInPictureMode(PiPParams)` (API 26+), `onPictureInPictureModeChanged()` me controls hide/show

### 4. ⬇️ Download Speed / ETA Display

**Kya hai:** Download chalte waqt live speed (MB/s) aur "X minute bache hain" dikhe.

**UI/UX (Downloads screen me):**
```
┌──────────────────────────────────────┐
│ movie.m3u8                    67%   │
│ ████████████████░░░░░               │

```

**User Workflow:**

4. Complete → "Done · 68 MB in 1:12"

**Code:**
- `HlsDownloader.kt` me already `downloaded/totalSize` count ho raha — bas **timestamps ka ring buffer** add karo (har 500ms sample) + `DownloadService` se UI ko throttle update (1/sec)
- `item_download_active.xml` me 2 TextView add

│ └────────────────────────────────┘ │
│ ✅ Completed (3)  ▾                │

```
- **Status colors:** 🟢 downloading · 🟡 paused · ⚪ queued · 🔴 failed · ✅ done

**User Workflow:**
